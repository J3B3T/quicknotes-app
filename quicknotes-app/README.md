 # QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to create, organise, search and delete notes. Notes can be assigned to Personal, Work or Study categories, and they are saved in the browser using localStorage so that they remain available after refreshing the page.

## Features

* Add new notes.
* Categorise notes as Personal, Work or Study.
* Delete individual notes.
* Search notes while typing.
* Validate empty notes.
* Limit notes to 200 characters.
* Display the total number of notes.
* Save notes using localStorage.
* Load saved notes when the page opens.
* Display the date and time each note was created.
* Responsive layout for smaller screens.
* Category-specific visual styles.

## How to Run the Project Locally

1. Download or clone the QuickNotes repository.
2. Open the `quicknotes-app` folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Start adding and managing notes.

The project does not require a server, database or external dependencies.
